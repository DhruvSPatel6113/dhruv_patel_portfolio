## Overview
Personal developer portfolio website showcasing software engineering projects, interactive simulations, and creative coding experiments built by Dhruv Patel.

## Features
- **Project Showcase**: Highlights key projects across machine learning, full-stack applications, and game development.
- **Interactive UI**: Responsive layouts, clean typography, smooth transitions, and mobile-friendly navigation.
- **Direct Links**: Embedded references to live web deployments, documentation, and source code.

## Tech Stack
- **HTML5**
- **CSS3** (Modern layout techniques, responsive breakpoints)
- **JavaScript**

## Running Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/DhruvSPatel6113/dhruv_patel_portfolio.git
   cd dhruv_patel_portfolio
   ```
2. Open `index.html` in any browser.
